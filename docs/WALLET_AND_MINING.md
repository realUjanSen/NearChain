# Wallet

- Keys are Ed25519, generated by the `cryptography` library.
- Address: `CDC` followed by 40 hex characters, the first 20 bytes of SHA-256 of the public key.
- The private seed is stored encrypted in `data/wallet.json`. The key is derived with scrypt
  and sealed with AES-GCM. Without the password, the file cannot be decrypted.
- Private keys are never sent over the network.
- Back up `data/wallet.json` and remember the password. There is no recovery if either is lost.

# Mining

Miner Mode uses SHA-256 proof of work. The miner builds a block from pending transactions,
then tries nonces until the hash meets the target.

- Foreground mode mines at full speed.
- Background mode pauses between batches (`background_sleep_ms` in `windows.yaml`).
- If another block arrives first, the miner drops its work and starts on the new tip.
- Rewards and fees go to the miner's address in the coinbase.
